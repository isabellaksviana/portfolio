# Portfólio

Meu site pessoal: https://isabellaviana.com

Feito em React com Vite e CSS puro, sem biblioteca de UI. Os componentes e os tokens vêm do meu Design System, o [ds-lab](https://github.com/isabellaksviana/ds-lab).

## Rodar

O portfólio usa o `ds-lab` de uma pasta vizinha (`file:../ds-lab`), então os dois repositórios precisam estar lado a lado:

```bash
npm install
npm run dev
```

Os textos ficam em `src/data/content.js`.
